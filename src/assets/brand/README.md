# Brand assets

| File | Use |
|---|---|
| `kunwu-emblem.svg` | Main emblem, simplified from the round logo: gold double ring, five-petal plum blossom, taiji. Header, footer, social image. Works on light and on ink backgrounds (it carries its own rice-paper disc). |
| `kunwu-taiji.svg` | Smallest mark: gold ring + taiji. Favicon and anything below ~32 px. |
| `source/round-logo-original.jpg` | Original round logo (reference only – too detailed for small sizes; ring text and figures do not survive scaling). |
| `source/monk-logo-original_AI-WATERMARK.jpg` | **Do not use publicly.** Carries a visible "豆包AI生成" (generated by Doubao AI) watermark bottom right, and the AI-drawn monk could be mistaken for a portrait of Master Shi Yanpeng. |

Raster icons in `public/` (favicon.ico, apple-touch-icon.png, icon-*.png, og-image.png, brand/*) are generated from the two SVGs:

```
npm run icons
```

Colors: gold `#B08A3E`, rice `#FAF5DC`, blossom `#E2674A` (outline `#B4442A`), ink `#000000`.
